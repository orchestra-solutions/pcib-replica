LUHN ALGORITHM VALIDATION

Validate card number against the Luhn Algorithm

What is the Luhn Algorithm?

The Luhn Algorithm is a general algorithm that enables you to verify and validate many types of identification numbers; in our case, the credit card number provided. 99% of all credit card numbers can be validated using the Luhn Algorithm to ensure that the card number provided is in the correct format.

With our 10 year experience processing credit cards, we have come across many exceptional cases of cards that do not match exactly into the standard Luhn Algorithm and we have expanded our Luhn validation to address all of these cases.

We offer a simple API that allows you to provide the card number entered and check if this card matches our expanded Luhn verification. No need to write your own code to implement the algorithm, no need to deal with out-of-the-ordinary cases, we handle it all.
